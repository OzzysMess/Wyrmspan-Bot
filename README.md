# Boardgame Optimization: Wyrmspan Bot
See full game [here](https://stonemaiergames.com/games/wyrmspan/).

This deck-building boardgame has a large action space, and I'd **roughly** estimate there's $10^{50}$ possible games. While not as many as chess, ($10^{120}$), there's still too many to brute force the best solution at each turn.

## What does this code do?
Use computers to try and maximize the final score

## Why?
My buddy Rios is too good at board games and doesn't let us win

## How?
I'll be trying my luck at 2 different approaches: Monte Carlo Tree Search, and a Machine Learning approach, method TBD.
